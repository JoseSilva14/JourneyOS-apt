JourneyOS packages

APT repository for JourneyOS (Debian 13 "trixie", amd64). JourneyOS installs already use it.

sudo curl -fsSLo /usr/share/keyrings/journeyos-archive-keyring.gpg https://josesilva14.github.io/JourneyOS-apt/journeyos-archive-keyring.gpg
echo "Types: deb
URIs: https://josesilva14.github.io/JourneyOS-apt
Suites: trixie
Components: main
Signed-By: /usr/share/keyrings/journeyos-archive-keyring.gpg" | sudo tee /etc/apt/sources.list.d/journeyos.sources
